# 🔍 Digital Forensics – Sleuth Kit

## Experiment No. 6: Use Sleuth Kit to Analyze Digital Evidence

### 📌 Objective

To use **The Sleuth Kit (TSK)** command-line tools to analyze disk images and recover digital evidence.

The Sleuth Kit is a collection of command-line tools that can be used to analyze disk images and recover digital evidence.

---

## 🛠️ Tools & Technologies

* **The Sleuth Kit (TSK)**
* **FTK Imager**
* **OSFMount** *(Optional)*
* **Windows Command Prompt**
* Digital Forensic Disk Images

---

The experiment uses the following disk image files:

```text
4Dell Latitude CPi.E01
```

These files are used as the evidence source for forensic analysis.

# 🧪 Step 4: Analyze the File System

## 4.1 Identify File System Information – `fsstat`

Use `fsstat` to obtain information about the file system.

```bash
fsstat [image file] > filesystem_info.txt
```

### Output

The command stores file system information in:

```text
filesystem_info.txt
```

This information helps understand the structure of the disk.

## 4.2 List Partitions – `mmls`

Use `mmls` to identify and list partitions present in the disk image.

```bash
mmls [image file] > partitions.txt
```

### Output

```text
partitions.txt
```

This file contains information about the partitions within the disk image.

## 4.3 List Files and Directories – `fls`

Use `fls` to recursively list files and directories.

```bash
fls -r [image file] > file_list.txt
```

### Output

```text
file_list.txt
```

The output contains files, directories, and associated metadata.

## 4.4 Recover Deleted Files – `icat`

The `icat` command can be used to extract a specific file using its inode number.

```bash
icat [image file] [inode number] > [output file]
```

The inode number can be obtained from the output generated by `fls`.

Example:

```bash
icat evidence.E01 12345 > recovered_file.txt
```

# 🕵️ Step 5: Analyze File Metadata

## 5.1 View Metadata – `istat`

Use `istat` to obtain detailed metadata associated with a file.

```bash
istat [image file] [inode number] > metadata_info.txt
```

The metadata can include:

* File timestamps
* File size
* Allocation status
* Other file-system information

Output:

```text
metadata_info.txt
```

---

# ⏱️ Step 6: Timeline Analysis

Timeline analysis can be used to understand file activity during an investigation.

## 6.1 Generate Body File

First, generate a body file using `fls`:

```bash
fls -m / -r [image file] > body.txt
```

Output:

```text
body.txt
```

---

## 6.2 Generate Timeline Using `mactime`

Use `mactime` to generate the timeline:

```bash
mactime -b body.txt > timeline.txt
```

Output:

```text
timeline.txt
```

The timeline contains **MAC times**:

* **M – Modified**
* **A – Accessed**
* **C – Changed**

# 🧰 Sleuth Kit Command Summary

| Tool      | Purpose                         | Command                      |
| --------- | ------------------------------- | ---------------------------- |
| `fsstat`  | Analyze file system information | `fsstat [image file]`        |
| `mmls`    | List partitions                 | `mmls [image file]`          |
| `fls`     | List files and directories      | `fls -r [image file]`        |
| `icat`    | Recover/extract a file          | `icat [image file] [inode]`  |
| `istat`   | Analyze file metadata           | `istat [image file] [inode]` |
| `mactime` | Generate forensic timeline      | `mactime -b body.txt`        |
